# Markdown To PDF

## 手順

1. 対象Markdownのパスを確認する。
2. Markdown内の見出し、表、リンクがPDF化に適した状態か確認する。
3. 利用可能な変換ツールを確認し、PDFを作成する。
4. 出力先とファイル名を報告する。

## 注意事項

- APの外部共有資料では、誇大な販売・勧誘表現、個人情報、未確定事項の断定に注意する。
- PDF化前に必要なら `markdown-maintenance-rules` で内容整理を提案する。
