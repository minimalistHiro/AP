# AP

AP事業向けのFlutterプロジェクトです。

このアプリは、化学物質を使わない化粧品・シャンプー等を扱うAP事業について、紹介活動そのものではなく、AI・データ化によるチーム支援を主軸にします。

## 初期方針

- AP基礎理論の整理
- 断り文句と切り返しノウハウの蓄積
- 参加理由・心理変化のデータ化
- リクルーター向け相談チャットボット構想
- プレゼン資料作成補助

詳しい文脈は `docs/AP_BUSINESS_CONTEXT.md` を参照してください。

## Codex

Codex向けの作業ルールは `AGENTS.md` にまとめています。

## 開発コマンド

```bash
flutter pub get
flutter analyze
flutter test
flutter run
```
