# QA Checklist Check

## 手順

1. `qa-checklist-rules` の方針を確認する。
2. `QA_CHECKLIST.md` を読む。
3. `qa/` 配下が存在する場合は、該当バージョンや最新ファイルも確認する。
4. 未確認項目、重点確認項目、AP特有の表現・個人情報リスクを整理して回答する。

## 注意事項

- チェック項目の消化だけを目的にしない。
- 気づいた不具合・改善案は `TODO.md` または `REVIEW_ITEMS.md` への追加候補として示す。
