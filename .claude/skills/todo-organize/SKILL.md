# TODO Organize

## 手順

1. `TODO.md` を読む。
2. `REVIEW_ITEMS.md` を読み、未決事項がTODOに混ざっていないか確認する。
3. 関連タスクを以下の観点でまとめる。
   - 同じ画面に関わるもの
   - 同じFirestore/API設計に関わるもの
   - AP文言・表現リスクに関わるもの
   - AI相談・資料生成・アンケートなど同じ機能群に属するもの
4. 整理案をユーザーに提示する。
5. 承認後に `TODO.md` を更新する。

## 注意事項

- 実装対象と未決論点を混ぜない。
- 優先度は、法務・個人情報・安全な表現に関わるものを高めに扱う。
