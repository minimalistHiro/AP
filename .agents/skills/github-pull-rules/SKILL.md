# GitHub Pull Rules

## 概要

APプロジェクトのリモートリポジトリから最新状態を取り込む。未コミット変更を壊さないことを最優先にする。

## 手順

1. `git status -sb` で現在ブランチと未コミット変更を確認する。
2. 未コミット変更がある場合は、pull前にユーザーへ確認する。
3. `git fetch origin` でリモート情報を更新する。
4. `git branch --all` でリモートブランチを確認する。
5. 対象ブランチが指定されていない場合は、原則として現在ブランチを対象にする。`main` を明示された場合のみ `main` に切り替える。
6. `git pull --ff-only` を基本とし、マージコミットが必要な場合はユーザーへ確認する。
7. 取り込んだ最新コミットと作業ツリー状態を報告する。

## 注意事項

- 未コミット変更を勝手に退避・破棄しない。
- コンフリクトが起きたら自動解決せず、対象ファイルと状況を報告する。
- `git reset --hard` はユーザーが明示した場合以外は禁止。
