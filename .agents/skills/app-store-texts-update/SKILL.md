# App Store Texts Update

## 手順

1. `APP_STORE_TEXTS.md` を読む。
2. `docs/AP_BUSINESS_CONTEXT.md`、`docs/AP_BUSINESS_MODEL.md`、`docs/AP_UI_TEXT_RULES.md` を確認する。
3. App Store / Google Play の文字数制限を意識して文案を作る。
4. APのアプリは「紹介活動そのもの」ではなく、AI・データ化によるチーム支援を主軸に表現する。
5. 更新後、文字数や表現リスクを報告する。

## 禁止・注意表現

- 収益が確実に得られるように見える表現
- 強い勧誘、加入を促す断定表現
- 医学的・美容的効果の保証
- 個人の悩みや参加理由を不用意に露出する表現
