# Review Items Check

## 手順

1. `REVIEW_ITEMS.md` を読む。
2. 必要に応じて `docs/AP_BUSINESS_CONTEXT.md`、`docs/AP_BUSINESS_MODEL.md`、`docs/AP_UI_TEXT_RULES.md` を読む。
3. 未決事項をカテゴリ別に整理して回答する。
4. 決定済みになった項目があれば、反映先MarkdownとTODO化の必要性を提案する。

## APで優先して管理する論点

- 勧誘表現・販売表現の安全性
- 初期費用や紹介報酬の説明方針
- 個人情報、相談ログ、参加理由アンケートの扱い
- AI回答の責任範囲
- 外部APIやFirestoreに保存するデータ範囲
