# TODO Check

## 手順

1. `TODO.md` を読む。
2. 必要に応じて `REVIEW_ITEMS.md` も読み、未決事項と実装TODOを混同しない。
3. 未着手、進行中、完了予定を整理して回答する。
4. TODO追加依頼の場合は `todo-add` または `todo-add-interactive` 相当の手順で追加する。

## 表示方針

- 優先度がある場合は高いものから表示する。
- APの安全性・個人情報・表現リスクに関わるものは別枠で示す。
